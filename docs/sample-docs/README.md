# Sample documents

Public-domain examples for the DBS KYC proof of concept.

| Folder | Use |
| --- | --- |
| `passport/` | Identity document biodata pages |
| `utilities/` | Proof of address (utilities bills) |
| `invoices/` | Commercial invoices / receipts (not used in the KYC name check) |

Drop additional `.jpg`, `.jpeg`, `.png` or `.pdf` files here if needed. Classification uses the page image, not the filename.
